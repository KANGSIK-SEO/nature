2. Engineering Verification and Results

2.1 Mathematical Audit of the AI Deduction: Exact Truth vs. Architectural Mismatch

The AI deduced that the 3-qubit bit-flip repetition code:

|ψk⟩ = cos(θk / 2)|000⟩ + sin(θk / 2)|111⟩

identically eliminates transverse coherences when tracing out syndrome ancillae q1 and q2. Performing the partial trace explicitly:

ρq0 = \text{Tr}1,2(|ψk⟩⟨ψk|) = cos2(θk / 2)|0⟩⟨0| + sin2(θk / 2)|1⟩⟨1|

Because ⟨00|11⟩ = 0, the off-diagonal coherence terms vanish identically:

⟨Xq0⟩ = \text{Tr}(ρq0 X) ≡ 0,   ⟨Yq0⟩ = \text{Tr}(ρq0 Y) ≡ 0,   ⟨Zq0⟩ = cos(θk)

[Engineering Audit Verdict 1]: Gemini 3.8 Flash's mathematical proof is an exact, unassailable quantum mechanical identity. The AI did not hallucinate.

[Physical Diagnosis]: However, the engineering failure was architectural: the 3-qubit repetition code stores phase information in the non-local entangled basis (|0L⟩ = |000⟩, |1L⟩ = |111⟩). To observe logical phase information, one must measure the logical Pauli operator ⟨X̄⟩ = ⟨X0 ⊗ X1 ⊗ X2⟩. Measuring the local single-qubit marginal (X0 ⊗ I ⊗ I) projectively erases tripartite entanglement. The collapse was not physical decay, but an engineering mismatch between an entangled code and unentangled local measurements.

2.2 Hardware Noise Decomposition: The Measured Non-Zero Values

If ⟨X⟩ = ⟨Y⟩ ≡ 0 identically, what generated the small readings (0.02 to 0.05) on the IBM transmon chips?

  1. Finite Shot Noise: With Nshots = 1024, the binomial standard error is σshot = 1/√1024 ≈ 0.03125.
  2. Readout Infidelity: State measurement assignment errors (eRO ≈ 1.5% to 2.2%) cause symmetric baseline offsets.
  3. CNOT Gate Inaccuracy: Two-qubit entangling gates introduce ≈0.8% infidelity.

Consequently, 20 out of 30 channels contained 0% image signal and 100% hardware noise. The Intraclass Correlation Coefficient (ICC ≤ 0.133) computed by the local daemon accurately identified this noise floor (Figure 1).

2.3 NAPOS QUBO Validation and Leakage-Free Generalization

The Noise-Aware Pauli Observable Selection (NAPOS) QUBO objective [4, 5] operates as an optimal signal-to-noise ratio (SNR) filter:

minb ∈ {0,1}M E(b) = − ∑k=1M (αdisc d̃k + αicc ICCk) bk + λ ∑k < l |Corr(Ok, Ol)| bk bl + μ (∑k=1M bk − K)2
